## 1. Overview
LifeQuest is a web app that turns daily tasks and habits into a game. Users can finish real-life tasks to earn XP, level up, and unlock rewards.

## 2. How to view it
* **Live Site:** You can open and test the site here: https://aaronsalunga098-ai.github.io/Life-Quest/
* **Local Setup:** You can also download or clone the repo and open `index.html` in any web browser.

## 3. Pages and features
* **Home (`index.html`):** The main dashboard showing user level, XP bar, and recent activity.
* **Quests (`quests.html`):** A task page where users can add, edit, and check off daily tasks.
* **Habits (`habits.html`):** A tracker page for daily habits and streak counts.
* **Rewards (`rewards.html`):** A shop page where users spend earned XP to unlock badges and rewards.

## What it is

LifeQuest is a gamified productivity website that turns everyday tasks and habits into quests, allowing users to earn XP, build streaks, and unlock badges as they make progress.

## How it is built

LifeQuest is built using HTML, CSS, and JavaScript, with each page connected through a navigation bar. The main pages are Home, which shows the player’s level, XP, streak, and priority quests; Quests, where users can add and complete tasks to earn XP; Habits, where users can track their daily habits and streaks; and Rewards, where users can view their statistics and unlock badges. The site uses a dark RPG-inspired design to make productivity more interactive and engaging.
