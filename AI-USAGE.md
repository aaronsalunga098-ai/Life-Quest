# 1. How We Used AI

AI was used by the group as an assistance tool during the development of LifeQuest. We used it for planning, revisions, explanations, troubleshooting, and reviewing parts of the project. We did not use AI to create the entire website. Each member also contributed code and reviewed the AI output before using it.

### Entry 1 - Project Planning

**Date:** September 2026
**Tool:** ChatGPT

**What we asked:**
We asked ChatGPT to help us plan the structure and features of LifeQuest, our gamified productivity and habit tracker.

**What AI gave back:**
AI suggested possible pages and features such as Home, Quests, Habits, Rewards, XP, levels, streaks, quests, and badges.

**What we kept/changed and why:**
We used some of the suggestions as ideas, but we decided the final structure and features based on our project requirements and group division of work.

# 2. Where AI Got It Wrong

AI was not treated as automatically correct. The group reviewed the output and corrected or questioned it when it did not match the project requirements or actual Git history.

### Case 1 - Misunderstanding the Professor's Starter Structure

**What AI gave:**
AI initially treated the professor's starter HTML structure as something that should be applied to the other LifeQuest pages as well.

**What was wrong:**
The starter structure was intended for the initial `index.html`. The other pages were allowed to have their own structures based on the project requirements.

**What we did instead:**
We clarified the requirement and used the starter structure as the basis for `index.html`, while creating custom structures for `quests.html`, `habits.html`, and `rewards.html`.

**Commit:**
[Add LifeQuest HTML pages - 2357ff0](https://github.com/aaronsalunga098-ai/Life-Quest/commit/2357ff0d1c223ef4f09d2e0a60e85ae94fdafaf9)

---

### Case 2 - Incorrect Attribution of Code

**What AI gave:**
AI initially suggested listing `script.js` as part of Aaron's contribution because he understood how the JavaScript interacted with his HTML.

**What was wrong:**
Understanding another member's code does not mean that Aaron wrote that code. Git history shows that Aaron's `2357ff0` commit contains the four HTML pages, while the later JavaScript work was committed by another group member.

**What we did instead:**
We checked the actual Git history and separated each member's contributions. Each member will only claim the files and commits they actually contributed.

**Commit used to verify the contribution:**
[Add LifeQuest HTML pages - 2357ff0](https://github.com/aaronsalunga098-ai/Life-Quest/commit/2357ff0d1c223ef4f09d2e0a60e85ae94fdafaf9)

---

### Case 3 - Security Problem With AI-Assisted Code

**What AI gave:**
AI-assisted JavaScript used `innerHTML` to display user-entered quest and habit names.

**What was wrong:**
Directly inserting user-entered content into HTML can create a security risk if the content is not safely handled.

**What we did instead:**
We identified the issue during the security review and documented it in the security checklist. We did not assume that AI-generated code was automatically safe just because it worked.
